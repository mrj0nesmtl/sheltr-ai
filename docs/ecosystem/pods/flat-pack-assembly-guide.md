## 🎯 Overview

This comprehensive guide provides detailed instructions for assembling the SHELTR Model A flat-pack emergency housing unit. With two people and basic tools, you can complete assembly in 2-4 hours.

**Assembly Time**: 2-4 hours  
**Team Size**: 2 people minimum  
**Skill Level**: Basic DIY skills required  
**Heavy Equipment**: None required

## 🔧 Phase 1: Foundation & Frame Assembly

**Time**: 45 minutes  
**Team**: 2 people

### Step 1: Floor Panel Installation (15 minutes)

**1.1 Position Floor Panel**
- Unpack floor panel (F1) from Pallet 2
- Place on level ground at final POD location
- Verify level in all directions using 2-foot level
- Adjust ground or use shims if necessary

**1.2 Secure Floor Panel**
- Install stabilizer legs at four corners
- Adjust leg height for perfect level
- Lock stabilizer legs in position
- Verify floor panel is stable and level

**Quality Check:**
- [ ] Floor panel level within ±0.5 degrees
- [ ] All four stabilizer legs making solid contact
- [ ] No rocking or movement
- [ ] Floor surface clean and dry

### Step 2: Frame Assembly (30 minutes)

**2.1 Identify Frame Components**
- Lay out all 12 frame sections (A-L) near floor panel
- Verify each piece is labeled correctly
- Inspect for damage during shipping
- Organize corner connectors and brackets

**2.2 Assemble Base Frame**
- Connect frame sections A, B, C, D to form base rectangle
- Use corner connectors at each corner
- Hand-tighten bolts initially (do not torque yet)
- Verify base frame is square (measure diagonals)

**2.3 Install Vertical Posts**
- Attach vertical frame sections (E, F, G, H) to base frame
- Use brackets to secure to floor panel
- Ensure posts are perfectly vertical (use level)
- Hand-tighten all connections

**2.4 Complete Top Frame**
- Connect top frame sections (I, J, K, L)
- Attach to vertical posts
- Verify frame is square and level
- Torque all bolts to specification (included torque wrench)

**Quality Check:**
- [ ] Frame is square (diagonals equal within 1/4")
- [ ] All vertical posts are plumb
- [ ] All connections tight (torqued to spec)
- [ ] Frame is rigid with no wobble
- [ ] All labels visible for next phase

**Safety Note:** Frame should be stable before proceeding. If frame feels unstable, recheck all connections and torque specifications.

## 🏗️ Phase 2: Panel Installation

**Time**: 60 minutes  
**Team**: 2 people

### Step 3: Wall Panel Installation (40 minutes)

**3.1 Prepare Wall Panels**
- Unpack wall panels (1-4) from Pallet 2
- Inspect gaskets (pre-installed on panel edges)
- Verify panels are labeled correctly
- Have weather sealing tape ready

**3.2 Install First Wall Panel (Panel 1)**
- Lift panel into position on frame
- Align bottom edge with floor panel
- Align side edges with frame posts
- Snap-fit connections should engage
- Secure with weatherproof bolts (hand-tighten first)

**3.3 Install Remaining Wall Panels (Panels 2, 3, 4)**
- Install panels in sequence (1→2→3→4)
- Ensure gaskets align between panels
- Snap-fit connections should engage with "click"
- Apply weather sealing tape to all joints
- Secure each panel with bolts

**3.4 Install Door Panel (D1)**
- Door comes pre-hung in panel
- Install door panel in designated opening
- Verify door swings freely
- Check door seal and gaskets
- Test smart lock mounting (do not install lock yet)

**3.5 Install Window Panels (W1, W2)**
- Windows integrated into wall panels
- Verify window operation (open/close)
- Check weather seals
- Ensure locking mechanisms function

**Quality Check:**
- [ ] All panels aligned and flush
- [ ] Gaskets properly seated at all joints
- [ ] Weather sealing tape applied to all seams
- [ ] Door swings freely and seals properly
- [ ] Windows open/close smoothly
- [ ] No gaps or misalignments

### Step 4: Roof Panel Installation (20 minutes)

**4.1 Prepare Roof Panels**
- Unpack roof panels (R1, R2) from Pallet 2
- Inspect EPDM rubber membrane
- Verify solar panel mounting points
- Check gaskets and seals

**4.2 Install Roof Panels**
- Lift first roof panel (R1) onto top frame
- Align with frame and wall panels
- Snap-fit connections should engage
- Secure with weatherproof bolts

- Install second roof panel (R2)
- Ensure panels overlap correctly
- Apply weather sealing tape to roof seam
- Secure all connections

**4.3 Final Weatherproofing**
- Apply weather sealing tape to all roof-to-wall joints
- Verify EPDM membrane is intact
- Check for any gaps or openings
- Inspect all panel connections

**Quality Check:**
- [ ] Roof panels properly aligned
- [ ] Roof-to-wall seams sealed
- [ ] EPDM membrane intact
- [ ] Solar mounting points accessible
- [ ] No visible gaps or leaks
- [ ] Roof is level and properly supported

**Safety Note:** Roof panels are heavy. Use proper lifting technique. Consider using step ladder for installation.

## ⚡ Phase 3: Systems Integration

**Time**: 45 minutes  
**Team**: 2 people

### Step 5: Electrical System Installation (25 minutes)

**5.1 Electrical Harness Installation**
- Unpack pre-wired electrical harness from Pallet 3
- Identify color-coded connectors
- Route harness through frame channels
- Secure harness with provided clips

**5.2 EcoFlow DELTA 2 Installation**
- Unpack EcoFlow DELTA 2 power station
- Install mounting bracket in entry area
- Secure DELTA 2 to bracket
- Connect to electrical harness (main power connector)

**5.3 Solar Panel Installation**
- Unpack solar panels (S1, S2) from Pallet 3
- Mount panels on roof using integrated mounting points
- Adjust tilt angle for optimal sun exposure
- Connect solar panels to DELTA 2 (pre-wired harness)

**5.4 Lighting Installation**
- Install LED lighting fixtures (2-3 zones)
- Connect to electrical harness (color-coded)
- Test lighting operation
- Verify dimming function (if equipped)

**5.5 System Testing**
- Power on EcoFlow DELTA 2
- Verify solar input (if sunny)
- Test all electrical outlets
- Test USB ports
- Verify lighting operation
- Check EcoFlow app connectivity

**Quality Check:**
- [ ] DELTA 2 securely mounted
- [ ] Solar panels properly connected
- [ ] All lighting fixtures operational
- [ ] Electrical outlets functioning
- [ ] USB ports working
- [ ] EcoFlow app connected
- [ ] No loose wires or connections

### Step 6: Plumbing System Installation (10 minutes)

**6.1 Water Tank Installation**
- Unpack 10L water tank from plumbing kit
- Install tank bracket under sink area
- Secure tank to bracket
- Connect fill port

**6.2 Plumbing Connections**
- Connect water pump to tank (quick-connect)
- Connect pump to sink faucet (quick-connect)
- Connect drain line (quick-connect)
- Verify all connections are secure

**6.3 System Testing**
- Fill water tank (test fill)
- Power on water pump
- Test faucet operation
- Check for leaks at all connections
- Verify drain function

**Quality Check:**
- [ ] Water tank securely mounted
- [ ] All quick-connect fittings secure
- [ ] No leaks at any connection
- [ ] Water pump operational
- [ ] Faucet operates smoothly
- [ ] Drain functions properly

### Step 7: Smart Lock Installation (10 minutes)

**7.1 Lock Preparation**
- Unpack smart lock from Pallet 3
- Verify all components present
- Review lock installation instructions

**7.2 Lock Installation**
- Install backing plate inside door
- Mount lock body through door
- Align with strike plate
- Secure with tamper-resistant fasteners

**7.3 Power Connection**
- Connect lock to 12V power (electrical harness)
- Verify backup battery is charged
- Test lock operation (manual)

**7.4 Digital Setup (to be completed later)**
- Lock pairing with platform (after full assembly)
- User enrollment (after handover)
- Access code setup (after handover)

**Quality Check:**
- [ ] Lock securely mounted
- [ ] Alignment with strike plate correct
- [ ] Mechanical operation smooth
- [ ] Power connected
- [ ] Backup battery charged

## 🔧 Troubleshooting

### Common Assembly Issues

**Frame Not Square:**
- **Symptom**: Diagonal measurements not equal
- **Solution**: Loosen connections, adjust frame, re-measure, re-torque

**Panels Not Aligning:**
- **Symptom**: Gaps between panels or panels not flush
- **Solution**: Check frame squareness, verify panel orientation, adjust gaskets

**Door Not Closing Properly:**
- **Symptom**: Door doesn't seal or latch
- **Solution**: Adjust door hinges, check frame alignment, verify strike plate position

**Electrical System Not Working:**
- **Symptom**: No power to outlets or lights
- **Solution**: Verify EcoFlow DELTA 2 is powered on, check harness connections, verify circuit breakers

**Plumbing Leaks:**
- **Symptom**: Water leaking from connections
- **Solution**: Tighten quick-connect fittings, verify gaskets are seated, check for damaged components

**Smart Lock Not Responding:**
- **Symptom**: Lock doesn't respond to inputs
- **Solution**: Check power connection, verify backup battery charged, reset lock if necessary
