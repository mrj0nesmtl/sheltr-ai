## 🚀 Quick Reference

### HTTP Status Codes
- `200` - Success
- `201` - Created
- `400` - Bad Request
- `401` - Unauthorized
- `403` - Forbidden
- `404` - Not Found
- `500` - Server Error

### User Roles
- `donor` - Can make donations
- `participant` - Service recipient
- `shelter_admin` - Shelter management
- `platform_admin` - Platform management
- `super_admin` - System administration
